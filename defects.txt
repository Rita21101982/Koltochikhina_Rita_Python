Баг_01
Ошибка в функции test_contains_negative при передаче пустого символа.

Шаги: вызвать функцию test_contains_negative с входящим текстом и
пустым значением символа.
        @pytest.mark.negative
        @pytest.mark.parametrize("input_str, symbol, expected", [
            ("python", "", False)])

        def test_contains_negative(input_str, symbol, expected):
            assert string_utils.contains(input_str, symbol) == expected

Ожидаемый результат: False - искомый символ в параметре отсутствует.

Фактический результат: "AssertionError: assert True == False".



Баг_02
Ошибка в функции test_contains_negative при передаче None 
в параметре "строка". 

Шаги: вызвать функцию test_contains_negative, передав в параметр строки None.
        @pytest.mark.negative
        @pytest.mark.parametrize("input_str, symbol, expected", [
            (None, "r", False)])

        def test_contains_negative(input_str, symbol, expected):
            assert string_utils.contains(input_str, symbol) == expected 

Ожидаемый результат: False - строка является обязательным параметром 
                     для передачи.

Фактический результат: AttributeError: 'NoneType' object has no attribute 
                      'index' - индекс None в данной функции не поддерживается.



Баг_03
Ошибка в функции test_delete_symbol_negative при передаче пробела 
в качестве символа.

Шаги: вызвать функцию test_delete_symbol_negative, передав в параметр строка - 
три пробела, в символ - один пробел.
пробел.   
        @pytest.mark.negative
        @pytest.mark.parametrize("string, symbol, expected", [
            ("   ", " ", "  ")])

        def test_delete_symbol_negative(string, symbol, expected):
            result = string_utils.delete_symbol(string, symbol)
            assert result == expected

Ожидаемый результат: из строки уберется один пробел и останется два пробела. 

Фактический результат: "AssertionError: assert '' == '  '" - пробел для передачи
                      символа не поддерживается.
